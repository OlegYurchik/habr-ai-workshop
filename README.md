# Habr AI Workshop: Expense Tracker

Практическое задание воркшопа — небольшой сервис для учёта личных расходов.

---

## Задача

Написать HTTP API сервис, который позволяет вести личный учёт расходов по категориям.

---

## Требования

### Категории

- Создать категорию с названием.
- Получить список всех категорий.

### Транзакции

- Создать транзакцию: сумма, описание (необязательно), категория, дата и время.
- Получить список транзакций. Поддерживаемые фильтры: по категории, по диапазону дат. Результат должен быть пагинирован.

### Отчёт

- Получить сводку расходов: итоговая сумма по каждой категории за выбранный период.

---

## Критерии готовности

- Все эндпоинты возвращают корректные данные и HTTP-статусы.
- Фильтрация и пагинация работают.
- Отчёт считает суммы правильно.
- Сервис покрыт тестами.
